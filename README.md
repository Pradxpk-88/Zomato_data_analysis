# 🍽️ Zomato Insights: Exploratory Data Analysis of Restaurant Trends

## 📌 Overview

Zomato Insights is a data analytics project focused on understanding restaurant trends, customer preferences, pricing patterns, and rating distributions using the Zomato dataset.

The project follows a complete data analysis workflow—from data cleaning and preprocessing to exploratory data analysis (EDA) and visualization. The goal is to transform raw restaurant data into meaningful insights that can support business decisions and improve customer experiences.

---

## 🎯 Objectives

* Clean and preprocess raw restaurant data
* Perform Exploratory Data Analysis (EDA)
* Identify trends in restaurant ratings and pricing
* Analyze customer preferences and service offerings
* Visualize relationships between key business variables
* Generate actionable insights from data
